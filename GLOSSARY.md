# Skey Notes

Notes are organized into named groups.

## Language

**Note group**:
A named collection of notes, displayed as a board column. Group membership does not represent a lifecycle or workflow status.
_Avoid_: Note status, note stage, note lifecycle

**System note group**:
Draft and Archive are fixed note groups whose names, visibility, and positions cannot be changed. Other note groups can be edited or removed while preserving their notes.
